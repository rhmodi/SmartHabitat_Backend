## Smart Habitat ##

Application is running on port `3001`.

## Installation Requirement ##
1. lombok jar :- [lombok](https://projectlombok.org/download)
2. Maven
3. Java 17 or higher


## Running Backend
1. To build the codebase run `mvn clean package`
2. To run use :- `mvn spring-boot:run`


## Important points to remember
1. Base API :-/api/smart-Habitat
2. port:- 3001
